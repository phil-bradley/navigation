# Navigation

A free and open-source reference guide to sailing navigation and seamanship.
The project covers COLREGS, buoyage, chartwork, pilotage, tides, lights,
shapes, and other topics relevant to recreational sailors, yachtmasters,
and boating students.

Includes the following chapters
* Shapes, Lights, Sounds
* Buoyage marks
* Steering and Sailing Rules
* Charts and tides
* Navigation

The latest PDF version can be found [here](https://raw.githubusercontent.com/phil-bradley/navigation/main/Notes.pdf).
